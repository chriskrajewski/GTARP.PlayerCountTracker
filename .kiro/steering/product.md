# Product Overview

RPStats.com is a real-time tracking and analytics platform for GTA RP (roleplay) servers, primarily FiveM-based.

## Core Features

- Real-time player count tracking for multiple GTA RP servers
- Live Twitch and Kick stream integration with viewer statistics
- Interactive charts with configurable time ranges (1h to all-time)
- Multi-stream viewer supporting simultaneous Twitch/Kick streams
- Server restart prediction using ML analysis of historical patterns
- Notification banner system for site-wide announcements
- Admin panel with visitor analytics, system health monitoring, and data management
- PWA support for mobile installation (iOS, Android, Desktop)

## Target Users

- GTA RP community members tracking server populations
- Streamers and viewers monitoring live content
- Server administrators analyzing player trends

## Key Integrations

- Supabase: Database, authentication, Edge Functions for data ingestion
- FiveM API: Live server player counts
- Twitch/Kick APIs: Stream and viewer data
- GitHub: Changelog and commit tracking
- Google Analytics & Mixpanel: User analytics
